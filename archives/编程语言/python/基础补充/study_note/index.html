一、基础概念（基于黑马笔记新增）

1.1、深浅拷贝

1.1.1 赋值

  • 会随着原对象一起改变
li = [1,2,3,4]
# print(li)
li2 = li # 将li直接赋值给li2
print('li', li)
print("li2",li2) 
li.append(5)  # 给li列表新增元素
print('新增后的li:', li)
print("新增后的li2:", li2)#赋值:等于完全共享资源，一个值的改变会完全被另一个值共享
###

1.1.2 浅拷贝（数据半共享）

  • 会创建新的对象，拷贝第一层的数据，嵌套层会指向原来的内存地址
  • 优点：拷贝速度快，占用空间少，拷贝效率高
import copy # 导入copy模块
li = [1, 2, 3, [4, 5, 6]]
li2 = copy.copy(li)
print('li', li)
print("li2",li2) 
print('li内存地址', id(li))
print("li2内存地址",id(li2)) 
li.append(8)            # 往第一层列表中添加元素，仅li添加此元素
li[3].append(7)         # 往嵌套列表添加元素,li与li2均会添加此元素
print('新增后的li:', li)  # 新增后的li: [1, 2, 3, [4, 5, 6, 7], 8]
print("新增后的li2:",li2) # 新增后的li2: [1, 2, 3, [4, 5, 6, 7]]

1.1.3 深拷贝（数据完全不共享）

  • 外层对象和内部元素均拷贝一遍，数据变化仅影响自己本身
  • 优点：拷贝速度快，占用空间少，拷贝效率高
import copy # 导入copy模块
li = [1, 2, 3, [4, 5, 6]]
li2 = copy.deepcopy(li)
print('li', li)
print("li2",li2) 
print('li内存地址', id(li))
print("li2内存地址",id(li2)) 
li.append(8)            # 往第一层列表中添加元素
li[3].append(7)         # 往嵌套列表添加元素
print('新增后的li:', li)  # 新增后的li: [1, 2, 3, [4, 5, 6, 7], 8]
print("新增后的li2:",li2) # 新增后的li2: [1, 2, 3, [4, 5, 6]]

1.1 查看所有的内置函数

import builtins
print(dir(builtins))
# 其中大写字母开头一般是内置常量名，小写字母开头一般是内置函数名

1.2 内置函数一

1.2.1 abs(): 返回绝对值
print (abs(-10))
print (abs(10))
# 打印信息均为10
1.2.2 sum()：求和
print (sum({1, 2, 3}))
print (sum((1, 2, 3)))
# sum函数内要放可迭代对象，注意：字符串不可以进行相加；运算时.只要有一个为浮点数，那么结果必定是浮点型

2.2 内置函数二

2.2.2 max()：求最大值
print (max(5,4,6))
