Python 学习笔记总览

本页合并了课程的基础语法、判断、循环、函数、数据容器、文件操作、异常处理、模块与包等笔记。示例面向 Python 3.x；课程来源为“黑马程序员 Python + AI 大模型零基础到项目实战”的 Python 部分。

更新日期：2026 年 10 月 15 日

一、基础语法

1. 字面量、变量与类型

字面量是直接写在代码中的值。变量名绑定到对象；对象本身有类型，名字可以重新绑定到其他类型的对象。

count = 10
count = "十"  # 重新绑定后，count 指向字符串对象

print(type(count))        # <class 'str'>
print(isinstance(10, int))  # True

常见内置类型：

类型示例是否可变
int10、-5否
float3.14否
boolTrue、False否
str"hello"否
NoneTypeNone否

Python 的整数可表示任意精度的整数；float 使用二进制浮点数，部分十进制小数不能精确表示，因此 0.1 + 0.2 == 0.3 的结果是 False。需要精确十进制金额计算时，应了解 decimal.Decimal。

2. 注释与文档字符串

# 这是单行注释


def add(a, b):
    """返回两个数的和。函数文档字符串写在函数体开头。"""
    return a + b

注释由 # 开始；文档字符串是模块、函数或类定义后紧跟的字符串，可供 help() 等工具读取。多行字符串本身不是注释。

3. 类型转换与真值

number = int("12")
price = float("3.5")
text = str(100)
flag = bool([])

int()、float()、str()、bool() 会按各自规则构造或转换对象；不合法的转换可能抛出 ValueError 或 TypeError。

条件判断会进行真值测试。False、None、数值零以及空字符串、空列表、空元组、空字典、空集合等为假；其他对象通常为真。

bool(0)       # False
bool("")      # False
bool([])      # False
bool("0")    # True

4. 运算符

类别运算符说明
算术+ - * / // % **加、减、乘、除、向负无穷取整的除法、余数、幂
比较== != < <= > >=比较结果通常为布尔值；可链式比较，如 0 < score <= 100
逻辑and or not逻辑组合，优先级依次由高到低为 not、and、or
赋值= += -= *= /= //= %= **=赋值与增强赋值

= 用于赋值，== 用于相等比较。逻辑运算符会短路求值；and 和 or 返回参与运算的对象，不保证返回 True 或 False。

x = 10
x += 5
x, y = 1, 2
x, y = y, x  # 交换绑定

age = 18
name = "小明"
is_adult = age >= 18
has_name = bool(name)
short_circuit_result = name and 42  # name 非空时，结果是 name；不是布尔值

5. 字符串

字符串可以使用单引号、双引号或三引号书写。字符串是不可变的 Unicode 文本序列；Python 没有独立的字符类型，单个字符也是长度为 1 的字符串。

single = 'hello'
double = "world"
multiline = """第一行
第二行"""

message = "第一行\n第二行"
path = r"C:\temp\notes"  # 原始字符串，反斜杠通常不作为转义符

字符串支持索引和切片，切片左端包含、右端不包含：

word = "Python"
word[0]       # "P"
word[-1]      # "n"
word[1:4]     # "yth"
word[::-1]    # "nohtyP"

常用方法包括 find()、index()、count()、replace()、split()、strip()。它们不会原地修改字符串；replace() 等会返回新字符串。strip(chars) 会从两端移除属于 chars 中任意字符的部分，不是移除一个固定子串。

text = "  Python, Python  "
cleaned = text.strip()
parts = cleaned.split(", ")
changed = cleaned.replace("Python", "Py")

优先使用 f-string 组合变量与格式说明：

name = "Morrow"
price = 19.99
print(f"{name}：{price:.2f} 元")
print(f"{1_000_000:,}")  # 1,000,000

二、输入与逻辑判断

input() 返回字符串。需要数字时要显式转换，并考虑用户输入不合法的情况。

name = input("请输入名字：")
try:
    age = int(input("请输入年龄："))
except ValueError:
    print("年龄必须是整数")
else:
    if age >= 18:
        print(f"{name} 已成年")
    else:
        print(f"{name} 未成年")

if、elif、else 根据条件从上到下判断，命中一个分支后不会再检查后面的分支。代码块通过缩进表示，通常使用 4 个空格。

score = 82
if score >= 90:
    grade = "优秀"
elif score >= 60:
    grade = "及格"
else:
    grade = "不及格"

三、循环

1. while

当条件为真时重复执行。要设计好条件更新，避免意外的无限循环。

i = 0
while i < 5:
    print(i)
    i += 1

2. for 与 range

for 逐个遍历可迭代对象中的元素；range(start, stop, step) 生成整数序列，stop 不包含在结果中。

for character in "Python":
    print(character)

for number in range(1, 6):
    print(number)  # 1 到 5

3. break 与 continue

  • break 结束当前所在的最内层循环。
  • continue 跳过当前这轮循环剩余语句，进入下一轮最内层循环。

四、函数

用 def 定义函数。函数可接收参数并用 return 返回结果；执行到 return 后函数立即结束。没有执行到有效 return 时，返回 None。

def add(a, b):
    """返回 a 与 b 的和。"""
    return a + b

result = add(2, 3)

1. 参数与返回值

def greet(name, greeting="你好"):
    return f"{greeting}，{name}"

greet("小明")
greet(name="小明", greeting="早上好")
  • 位置参数按位置传入；关键字参数按参数名传入。
  • 有默认值的参数通常放在无默认值的参数之后。
  • 调用时，位置参数应放在关键字参数之前。
  • return a, b 等价于返回一个二元组，可用 x, y = function() 解包。

可变参数：

def show_members(team, *members, **details):
    print(team)
    print(members)  # 多余的位置参数收集为元组
    print(details)  # 多余的关键字参数收集为字典

show_members("学习小组", "小明", "小红", city="深圳")

2. 作用域与函数说明

函数内部赋值的名字通常是局部变量。global name 声明函数内对 name 的赋值使用模块级名字；应优先通过参数和返回值传递状态，减少对全局变量的依赖。Python 还存在外层函数作用域和内置作用域。

文档字符串写在函数体第一行：

def area(width, height):
    """计算矩形面积。"""
    return width * height

3. 函数作为值与 lambda

函数可以作为参数传递。lambda 用于创建只包含一个表达式的匿名函数；它并非只能使用一次，但复杂逻辑应使用 def。

def apply(operation, a, b):
    return operation(a, b)

result = apply(lambda x, y: x + y, 2, 3)

4. 综合练习：简易 ATM

下面的示例覆盖输入、判断、循环、函数与状态更新，可直接运行：

def main():
    name = input("请输入姓名：").strip() or "访客"
    balance = 5_000_000

    while True:
        print(f"\n{name}，请选择：1 查询余额  2 存款  3 取款  4 退出")
        choice = input("操作编号：").strip()

        if choice == "1":
            print(f"当前余额：{balance} 元")
        elif choice in {"2", "3"}:
            try:
                amount = int(input("金额（正整数）："))
            except ValueError:
                print("请输入有效整数。")
                continue

            if amount <= 0:
                print("金额必须大于 0。")
            elif choice == "2":
                balance += amount
                print(f"存款成功，当前余额：{balance} 元")
            elif amount <= balance:
                balance -= amount
                print(f"取款成功，当前余额：{balance} 元")
            else:
                print("余额不足。")
        elif choice == "4":
            print("再见！")
            break
        else:
            print("无效选项，请重新输入。")


if __name__ == "__main__":
    main()

五、数据容器

类型是否可变顺序与访问常见用途
list 列表可变有序，可索引，可重复保存可增删改的一组元素
tuple 元组不可变有序，可索引，可重复保存不需要改动的元素组
str 字符串不可变有序，可索引文本处理
set 集合可变无序，不支持索引，元素唯一去重、成员测试、集合运算
dict 字典可变按键访问；Python 3.7 起语言保证保留插入顺序键值映射

可哈希对象可用作集合元素和字典键。常见不可变对象（如整数、字符串）通常可哈希；列表、字典和可变集合不可哈希。元组只有在其所有元素也可哈希时才可哈希。集合本身不可哈希；需要不可变集合时可了解 frozenset。

1. 列表、元组与切片

items = ["Python", 3, True]
items.append("新元素")
items.extend([4, 5])
items[0] = "Python 3"
removed = items.pop()          # 删除并返回末尾元素
items.remove(True)             # 删除第一个匹配项；不存在时会抛出 ValueError

point = (10, 20)
coordinates = (10,)            # 单元素元组需要逗号

numbers = [0, 1, 2, 3, 4]
numbers[1:4]                   # [1, 2, 3]
numbers[::-1]                  # 反向切片

列表常用 append()、extend()、insert()、remove()、pop()、clear()、index()、count()、sort()；元组常用 index()、count()。遍历通常直接使用 for item in items。

2. 字符串

字符串也是序列，支持索引、切片和遍历。它不可变，修改操作会返回新字符串。

text = "  a,b,c  "
text.strip().split(",")
"python".replace("p", "P")

3. 集合

非空集合可用 {...} 创建；空集合要用 set()，因为 {} 表示空字典。集合元素必须可哈希，集合不保留插入顺序；pop() 移除一个元素，但不承诺是哪一个。

languages = {"Python", "C", "Python"}  # 重复元素只保留一个
languages.add("Rust")
languages.discard("不存在也不会报错")
left = {1, 2, 3}
right = {3, 4}
left | right   # 并集
left & right   # 交集
left - right   # 差集

4. 字典

字典键必须可哈希。重复赋值会更新同一个键；值可以是任意对象。

person = {"name": "小明", "age": 18}
person["age"] = 19
person["city"] = "深圳"
age = person.get("age")
removed_age = person.pop("age")

for key, value in person.items():
    print(key, value)

empty_dict = {}
empty_set = set()

5. 通用操作与转换

len() 可取得容器元素数量，in 可做成员测试；min()、max() 和 sorted() 要求参与比较的值能够互相比较。sorted() 返回新列表，不会原地修改输入。

values = [3, 1, 2]
ordered = sorted(values)
descending = sorted(values, reverse=True)

list("abc")       # ['a', 'b', 'c']
tuple([1, 2])     # (1, 2)
set([1, 1, 2])    # {1, 2}
list({"a": 1})    # 遍历字典得到键

容器构造函数接收的对象需要满足相应要求；例如 dict() 通常接收键值对序列或映射，不能把任意列表直接转换成字典。

六、文件操作

文本文件应明确指定编码。with 语句会在离开代码块时关闭文件，即使读取或写入时发生异常也会执行清理。

模式用途
"r"读取，文件必须存在
"w"写入；已有文件会被清空，不存在则创建
"a"追加到文件末尾，不存在则创建
"x"独占创建；文件已存在时失败
"b"二进制模式修饰符，例如 "rb"；二进制模式不使用 encoding
with open("word.txt", "r", encoding="utf-8") as file:
    text = file.read()
    print(text.count("itheima"))

with open("result.txt", "w", encoding="utf-8") as file:
    file.write("处理完成\n")

read() 读取内容，readline() 读取一行；遍历文件对象适合逐行处理较大的文本。对于跨平台路径，可使用标准库 pathlib.Path。

七、异常处理

语法错误通常在解析代码时发现；异常是在执行时发生的错误。使用针对性的 except 处理预期异常，避免用裸 except 隐藏所有错误。

try:
    age = int(input("年龄："))
except ValueError as error:
    print(f"输入无效：{error}")
else:
    print(f"输入的年龄是 {age}")
finally:
    print("输入处理结束")
  • try 放置可能抛出异常的代码。
  • except SomeError 处理指定异常类型；except Exception 可处理大多数常规异常，但不会捕获继承自 BaseException 的所有退出信号。
  • else 在 try 没有异常时运行。
  • finally 无论是否发生异常都会运行，常用于清理资源；文件通常优先用 with。
  • 未处理的异常会沿调用栈向上传播。

八、模块、包与第三方库

模块通常是包含 Python 代码的 .py 文件。常见导入方式：

import math
import math as m
from pathlib import Path

from module import * 会把多个名字引入当前命名空间，通常不利于阅读和排查名称冲突。

模块可以用下面的入口判断区分“直接运行”与“被导入”：

def main():
    print("程序入口")


if __name__ == "__main__":
    main()

普通包通常是包含 __init__.py 的目录；Python 也支持不含该文件的命名空间包。第三方包可通过 pip 安装，常用命令为：

python -m pip install 包名

建议在虚拟环境中安装项目依赖，避免不同项目的依赖互相影响。
