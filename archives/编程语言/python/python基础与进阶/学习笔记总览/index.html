3. if-elif-else

    条件1成立时，要做的事情（仅在满足条件1时执行）

else :
    所有条件不成立时，要做的事情（仅在不满足所有条件时执行）
注：py语句中用缩进来表示归属关系，要求是4个空格
判断有顺序且互斥，顺序执行后满足其中一条条件就不会继续执行
"""
score = int(input("成绩："))
if score >= 90:
    print("优秀")
elif score >= 60:
    print("及格")
else:
    print("不及格")

三、循环

1. while 循环

"""
while 条件:
    条件成立时，要做的事情1
    条件成立时，要做的事情2
    …………
若想做到有限次数循环，有三个要素：
    1、循环控制因子（某个变量）
    2、循环控制条件（基于因子做判断）
    3、循环因子更新（修改因子的值，令因子可以在某一刻不满足条件）
"""
i = 0
while i < 5:
    print(i)
    i += 1
  • 注：多层嵌套尽量避免，三层以上的嵌套大概率可以通过算法优化

2. for 循环

  • for循环是一种轮询机制，是对一批内容进行逐个处理
  • 无法定义循环条件，只能被动取出数据处理
"""
for 临时变量 in 待处理数据集:
    循环条件满足时执行的代码
- range语句可以获取一个数字序列（可迭代类型的一种）
"""
for i in range(5):
    print(i)

3. break / continue

  • break关键字：
    • 直接结束循环，只作用在本身所在循环
    • 可用于for循环和while循环
  • continue关键字：
    • 中断本次循环，直接进入下一次循环
    • 仅可控制自身所在循环的临时终端
    • for循环和while循环均可使用，效果一致

四、函数

1. 定义函数

  • 函数特征：组织好的，可重复使用的，用来实现特定功能的代码段
  • 将功能封装在函数内，可供随时随地重复使用
  • 函数封装可提高代码的复用性，减少重复代码，提高效率
"""
def 函数名([传入参数]):
    函数体
    [return]
调用：函数名([参数])
返回值：函数再执行完成后，返回给调用者的结果，return后的代码不会执行
若函数无返回值，则结果为None
None作用：函数无返回值；if判断中等同false；定义无内容的变量
"""
def add(a, b):
    return a + b

2. return 与 None

  • return 用于返回结果
  • 未写 return → 默认返回 None

3. 参数类型

参数说明
位置参数按顺序
默认参数提供默认值
关键字参数指定名称
def func(a, b=10):
    return a + b

  • 内容通常写在函数体之前
  • 标准的注释可以帮助理解函数使用函数

def func(x, y):
    """
    # 函数说明
    # :param x：形参x的说明
    # :param y：形参y的说明

    """
    函数体

5. 变量作用域

  • 通常分为局部变量和全局变量
  • 局部变量：定义在函数体内部的变量，仅在函数体内部生效
    • 可用于临时保存数据，函数调用完成后则销毁局部变量
    • 使用global关键字，即使在函数体内定义，仍为全局变量
  • 全局变量：在函数体内、外均可生效的变量

6. 综合实践

  • 实现一个黑马ATM的效果
    • 默认余额为5000000元
    • 程序启动后要求输入客户姓名
    • 主菜单提示客户姓名的欢迎词，可以实现查询余额、存款、取款、退出四个功能
    • 除退出外，执行完对应任务可以返回到主菜单
    • 存款、取款后都应显示当前余额
    • 客户选择退出或输入错误，程序会退出，否则一直运行
"""
print("欢迎来到黑马ATM")
name = input("请输入您的名字：")
money = 5000000
withdrawal_num = None
def main_screen():
    """
    ATM案例的主菜单函数，提示用户做输入，并返回用户输入的数字
    :return: 用户输入的数字
    """
    print('-'*10 + "主菜单" + "-"*10)
    print(f"{name}，您好，欢迎来到ATM，请选择操作：")
    print("查询余额 [输入1]")
    print("存款    [输入2]")
    print("取款    [输入3]")
    print("退出    [输入4]")
    return int(input("请输入您的选择："))
def balance_inquiry(selcet):
    """
    查询用户银行余额
    :return: None
    """
    if selcet != 0:
        print("----------------查询余额-----------------")
    print(f"{name}，您好,您的余额剩余：{money}元")
def deposit():
    """
    向用户余额存钱
    :return: None
    """
    global money
    print('-'*10 + "存款" + "-"*10)
    num = int(input(f"{name}，您好，您要存入多少元（请输入整数）："))
    print(f"{name}，您好,您存款{num}元成功")
    money += num
    balance_inquiry(0)
def withdrawal():
    global money
    print('-'*10 + "取款" + "-"*10)
    num = int(input(f"{name}，您好，您要取出多少元（请输入整数）："))
    if money > num:
        money -= num
        print(f"{name}，您好,您取款{num}元成功")
    else:
        print(f"{name}，您好,您取款{num}元失败")
    balance_inquiry(0)
while True:
    selcet = main_screen()
    if selcet == 1:
        balance_inquiry(1)
    elif selcet == 2:
        deposit()
    elif selcet == 3:
        withdrawal()
    else:
        print("欢迎下次来临，再见！")
        break

序列的切片

1. 序列

  • 序列：指内容连续、有序、可使用下标索引的一类数据容器（列表、元组、字符串）
  • 切片：从一个序列中，取出一个子序列
  • 语法：序列[起始下标:结束下标:步长] #均可省略，省略则视为默认值，从头:到尾:1

2. 示例

lst = [0, 1, 2, 3, 4, 5, 6, 7]
print(lst[::])                      #按序取出列表中所有元素
print(lst[::-1])                    #按反序取出列表中所有元素
print(lst[3:5:])                    #取出3，4两个元素

  • 语法：{元素，元素，元素} / set()
my_set = {0, 1, 2, 3, 4}

2. 集合的方法

my_set = {0, 1, 2, 3, 4}
set2 = {0, 7, 9, 10}
my_set.add(5)                   #添加一个元素，插入位置不确定
my_set.remove(4)                #移除指定元素
my_set.pop()                    #随机取出一个元素
my_set.clear()                  #清空集合
my_set.difference(set2)         #取差集并返回一个新的集合,(my_set有但set2没有的元素)
my_set.difference_update(set2)  #删除my_set中和set2相同的元素
my_set.union(set2)              #集合并集，返回新的集合
len(my_set)                     #统计元素数量

3. 遍历集合

  • 仅可使用for，无法使用while
my_set = {0, 1, 2, 3, 4}

for x in my_set:
    print(x)

5️⃣ dict（字典）

  • 键唯一，值可重复，有序，无下标，使用key进行查询操作
  • key不可是数据容器，value可是任意类型
  • key重复添加会覆盖原有数据

1. 字典定义

  • 语法：{key: value, key: value, ……, key:value} / set() / {}
d1 = {"name": "Tom", "age": 18}
d2 = {}                             #定义空字典
d3 = set()                          #定义空字典

2. 字典嵌套

  • key不可为字典（通常使用整数/字符串）
d1 = {"Tom":{"age": 18, "gender": "man"},
      "Wie":{"age": 12, "gender": "woman"},
      "Sea":{"age": 11, "gender": "woman"}
      }

3. 字典的方法

d = {"name": "Tom", "age": 18}
d["name"] = "Tim"               #新增/修改元素, 若key存在则修改，key不存在则新增
d.pop["name"]                   #删除某个key,并返回其对应的value
d.clear()                       #清空字典
d.keys()                        #获取字典的全部key
len(d)                          #计算字典中键值对的数量

4. 遍历字典

  • 仅可使用for，无法使用while
d1 = {"Tom":{"age": 18, "gender": "man"},
      "Wie":{"age": 12, "gender": "woman"},
      "Sea":{"age": 11, "gender": "woman"}
      }
for key in d1:
    print(f"{d1}:{d1[key]}")

六、函数进阶

1️⃣ 函数返回多返回值

def func():
    # 就是返回了（1，2）的元组
    return 1, 2
print(type(func()))             #输出结果： <class 'tuple'>

2️⃣ 函数的多种传参方式

1. 位置参数

  • 调用函数时根据函数定义的参数位置来传递参数
  • 传递的参数和定义的参数的顺序和个数必须一致
def user_info(name, age, gender):
    print(f"您的名字是{name}, 年龄是{age}, 性别是{gender}")
user_info("Tom", 20, "男")   #输出结果：您的名字是Tom, 年龄是20, 性别是男

2. 关键字参数

  • 函数调用时通过“键=值”形式传递参数
  • 作用：可以让函数更加清晰、容易使用，同时也清除了参数的顺序需求.
  • 函数调用时，如果有位置参数时，位置参数必须在关键字参数的前面，但关键字参数之间不存在先后顺序
def user_info(name, age, gender):
    print(f"您的名字是{name}, 年龄是{age}, 性别是{gender}")
user_info(age=20, name="Tom", gender="男")   #输出结果：您的名字是Tom, 年龄是20, 性别是男
# 可以和位置参数混用，位置参数必须在前，且匹配参数顺序
user_info("Tom", age=20, gender="男")        #输出结果：您的名字是Tom, 年龄是20, 性别是男

3. 缺省参数（默认参数）

  • 用于定义函数，为函数提供默认值，调用函数时可不传达改默认参数的值
  • 所有位置参数必须出现在默认参数前，包括函数定义和调用
  • 当调用函数时没有传递参数，就会使用默认缺省参数对应的值
def user_info(name, age, gender = "男"):
    print(f"您的名字是{name}, 年龄是{age}, 性别是{gender}")
user_info("Tom", 20)   # 输出结果：您的名字是Tom, 年龄是20, 性别是男
# 函数调用时，如果为缺省参数传值则修改默认参数值，否则使用这个默认值
user_info("Tom", 20, "女")        # 输出结果：您的名字是Tom, 年龄是20, 性别是女

4. 不定长参数（可变参数）

  • 用于不确定调用的时候会传递多少个参数（不传参也可）
  • 通常将不定长参数命名为*args
位置传递（元组接收）
def func(name, *args):
    print(f"我们是{name}, 我们的成员有：", end="")
    for i in xxx:
        print(i, end=" ")
func("黑马", "周杰伦", "王力宏", "张学友", "刘德华")  
# 输出结果：我们是黑马, 我们的成员有：周杰伦 王力宏 张学友 刘德华
关键字传递（字典接收）
def func(name, **kwargs):
    print(kwargs)
func("aa", id = 1, age = 11, gender = "男", addr = "深圳石岩")  
# 输出结果：{'id': 1, 'age': 11, 'gender': '男', 'addr': '深圳石岩'}

3️⃣ 匿名函数

1. 函数作为参数传递

  • 形参：可以接收函数传入
  • 实参：传入实际函数
def func(compute):
    result = compute(1, 2)
    print(result)
def compute(x, y):
    return x + y
func(compute)   # 输出结果：3

2. lambda匿名函数

  • 函数定义中，def可以定义有名称的函数，lambda可以定义匿名函数（无名称）
  • 无名称的匿名函数，只可临时使用一次，也只能写一行代码
  • 如果想要重复使用匿名函数，可以将匿名函数赋值给变量
"""
定义方式： lambda 传入参数 : 函数体
"""
def func(compute):
    result = compute(1, 2)
    print(result)
func(lambda x, y: x+y)   # 输出结果：3

七、文件操作

1️⃣ 文件编码的概念

  • 编码是一种规则集合，记录了内容和二进制间的对应关系
  • 同样的字符在不同编码中对应的二进制不同
  • UTF-8是目前全球通用的编码格式

2️⃣ 文件的打开、关闭、读取

"""
open(name, mode, encoding) # 打开或创建一个文件
name:       要打开的目标文件名的字符串（可以包含文件所在的具体路径）
mode:       设置打开文件的模式：r(只读)、w(写入)、a(追加)、b(二进制处理)等
encoding:   编码格式（通常为UTF-8）
文件对象.read(num)     # 读取文件中num长度的数据，默认读取全部
文件对象.readline()    # 读取文件中一行
文件对象.readlines()   # 按照整行的方式把整个文件中内容进行一次性读取，并返回一个列表，每一行数据为一个元素
文件对象.close()       # 关闭文件对象
with open() as f:    # 此语法将文件打开并赋值给f，自动调用close()
文件对象.write()       # 写入文件,若文件以w模式开启则会清空已有文件，以a模式可以在已有文件内容后追加
"""
f = open("README.md", "r", encoding="utf-8")
f = open("README.md", "r", encoding="utf-8")
print(f.read(10))
print(f.readline())
print(f.readlines(100))
for line in f:
    print(line.strip())
f.close()
with open("README.md", "r", encoding="utf-8") as f:
    for line in f:
        print(line.strip())

八、异常、模块与包

1️⃣ 异常

  • 程序运行中的错误

🪝捕获异常

  • 提前假设某处会出现异常，做好提前准备
# try:
#     可能发生错误的代码，只有在try内部的代码才会被捕获异常
# except:                           # except Exception as e: 捕获全部异常
# except 异常类型 as 变量:            # 针对特定异常做捕获（可使用多个except区分不同异常类型）
# except (异常类型, 异常类型) as e:    # 针对多个特定异常做捕获,但无法区分
#     如果出现错误执行的代码
# else:
#     无异常执行的代码
# finally:
#     无论有无异常都执行的代码
try:
    f = open("word.txt", "r", encoding="utf-8")
except FileNotFoundError as e:
    f = open("word.txt", "w", encoding="utf-8")
    print(e)
print(f.read())
f.close()

异常的传递性

  • 异常具有传递性，会将下层函数出现的异常传递给上层函数，若所有函数均为捕获异常，程序会报错
  • 利用这一特性可以在main函数中设置异常捕获，以保证程序正常运行

2️⃣ 模块

模块的导入

  • 模块是python文件，内涵模块、函数、类、变量等
  • 常用导入方式语法为：[form 模块名] import [模块 | 类 | 变量 | 函数 | 方法 | *] [别名]
  • 常用组合如下
    • import 模块名
    • import 模块名 as 别名
    • from 模块名 import 类、变量、方法等（用的时候无需模块.功能）
    • from 模块名 import * (导入模块中所有功能，但不建议使用，可读性差)
    • from 模块名 import 功能名 as 别名

自定义模块

# 如果本文件被直接执行，则内置变量__name__会被赋值为__main__
# 如果本文件被import或from导入，则内置变量__name__会被赋值为文件名称
# __name__是Python内置变量，任何代码文件都有
# 我们可以通过读取这个变量的值，从而确定这个代码文件是：被人导入了还是被作为程序执行了
if __name__ == '__main__':
    print("main")
