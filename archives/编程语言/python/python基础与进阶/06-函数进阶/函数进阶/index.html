Python 函数进阶

六、函数进阶

1️⃣ 函数返回多返回值

def func():
    # 就是返回了（1，2）的元组
    return 1, 2
print(type(func()))             #输出结果： <class 'tuple'>

2️⃣ 函数的多种传参方式

1. 位置参数

  • 调用函数时根据函数定义的参数位置来传递参数
  • 传递的参数和定义的参数的顺序和个数必须一致
def user_info(name, age, gender):
    print(f"您的名字是{name}, 年龄是{age}, 性别是{gender}")
user_info("Tom", 20, "男")   #输出结果：您的名字是Tom, 年龄是20, 性别是男

2. 关键字参数

  • 函数调用时通过“键=值”形式传递参数
  • 作用：可以让函数更加清晰、容易使用，同时也清除了参数的顺序需求.
  • 函数调用时，如果有位置参数时，位置参数必须在关键字参数的前面，但关键字参数之间不存在先后顺序
def user_info(name, age, gender):
    print(f"您的名字是{name}, 年龄是{age}, 性别是{gender}")
user_info(age=20, name="Tom", gender="男")   #输出结果：您的名字是Tom, 年龄是20, 性别是男
# 可以和位置参数混用，位置参数必须在前，且匹配参数顺序
user_info("Tom", age=20, gender="男")        #输出结果：您的名字是Tom, 年龄是20, 性别是男

3. 缺省参数（默认参数）

  • 用于定义函数，为函数提供默认值，调用函数时可不传达改默认参数的值
  • 所有位置参数必须出现在默认参数前，包括函数定义和调用
  • 当调用函数时没有传递参数，就会使用默认缺省参数对应的值
def user_info(name, age, gender = "男"):
    print(f"您的名字是{name}, 年龄是{age}, 性别是{gender}")
user_info("Tom", 20)   # 输出结果：您的名字是Tom, 年龄是20, 性别是男
# 函数调用时，如果为缺省参数传值则修改默认参数值，否则使用这个默认值
user_info("Tom", 20, "女")        # 输出结果：您的名字是Tom, 年龄是20, 性别是女

4. 不定长参数（可变参数）

  • 用于不确定调用的时候会传递多少个参数（不传参也可）
  • 通常将不定长参数命名为*args
位置传递（元组接收）
def func(name, *args):
    print(f"我们是{name}, 我们的成员有：", end="")
    for i in xxx:
        print(i, end=" ")
func("黑马", "周杰伦", "王力宏", "张学友", "刘德华")  
# 输出结果：我们是黑马, 我们的成员有：周杰伦 王力宏 张学友 刘德华
关键字传递（字典接收）
def func(name, **kwargs):
    print(kwargs)
func("aa", id = 1, age = 11, gender = "男", addr = "深圳石岩")  
# 输出结果：{'id': 1, 'age': 11, 'gender': '男', 'addr': '深圳石岩'}

3️⃣ 匿名函数

1. 函数作为参数传递

  • 形参：可以接收函数传入
  • 实参：传入实际函数
def func(compute):
    result = compute(1, 2)
    print(result)
def compute(x, y):
    return x + y
func(compute)   # 输出结果：3

2. lambda匿名函数

  • 函数定义中，def可以定义有名称的函数，lambda可以定义匿名函数（无名称）
  • 无名称的匿名函数，只可临时使用一次，也只能写一行代码
  • 如果想要重复使用匿名函数，可以将匿名函数赋值给变量
"""
定义方式： lambda 传入参数 : 函数体
"""
def func(compute):
    result = compute(1, 2)
    print(result)
func(lambda x, y: x+y)   # 输出结果：3
