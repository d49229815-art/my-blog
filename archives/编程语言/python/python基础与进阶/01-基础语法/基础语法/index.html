Python 基础语法

一、基础语法

1、基础概念

1. 字面量（Literal）

字面量是直接写在代码中的固定值，程序运行期间不会发生改变。

类型示例
整数10, -5
浮点数3.14
字符串“hello”
布尔True / False
空值None
print(10)
print("hello")
print(True)
print(None)

2. 变量（Variable）

变量是对象的引用名称，并不保存数据本身。

x = 10
x = "hello"

📌 特点：

  • 变量本身无类型
  • 数据对象有类型
  • 可反复赋值

3. 字面量与变量（Variable）

概念说明注意事项
字面量直接写在代码中的固定值尽量避免直接使用，优先使用变量
变量存储运行过程中数据的容器可重复使用、可修改、命名需规范

3. 字符串格式化

# 1. 拼接
name = "Alice"
greeting = "Hello, " + name + "!"
# 2. 重复
divider = "-" * 30  # "------------------------------"
# 3. 格式化（三种方式）
price = 19.99
quantity = 3

# 方式1: %格式化（旧式）
message = "单价: %.2f元，数量: %d，总价: %.2f元" % (price, quantity, price * quantity)
# 方式2: format方法（推荐）
message = "单价: {:.2f}元，数量: {}，总价: {:.2f}元".format(price, quantity, price * quantity)
# 方式3: f-string（Python 3.6+，最简洁）
message = f"单价: {price:.2f}元，数量: {quantity}，总价: {price * quantity:.2f}元"

# 格式化语法细节
# {变量:格式说明符}
#   :.2f  - 保留2位小数
#   :8d   - 宽度8，右对齐整数
#   :<10s - 宽度10，左对齐字符串
#   :^10s - 宽度10，居中对齐字符串
#   :,    - 千位分隔符（仅数字）
num = 1000000
print(f"{num:,}")  # 输出: 1,000,000
