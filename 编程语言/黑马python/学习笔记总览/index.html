    一、基础语法

    1、基础概念

    1. 字面量（Literal）

    字面量是直接写在代码中的固定值，程序运行期间不会发生改变。

    类型 示例
    整数 10, -5
    浮点数 3.14
    字符串 "hello"
    布尔 True / False
    空值 None 
    print(10)
print("hello")
print(True)
print(None)

    2. 变量（Variable）

    变量是对象的引用名称，并不保存数据本身。

    x = 10
x = "hello"

    📌 特点： - 变量本身无类型 - 数据对象有类型 - 可反复赋值

    3. 字面量与变量（Variable）

    概念 说明 注意事项
    字面量 直接写在代码中的固定值 尽量避免直接使用，优先使用变量
    变量 存储运行过程中数据的容器 可重复使用、可修改、命名需规范

    3. 字符串格式化

    # 1. 拼接
name = "Alice"
greeting = "Hello, " + name + "!"
# 2. 重复
divider = "-" * 30  # "------------------------------"
# 3. 格式化（三种方式）
price = 19.99
quantity = 3

# 方式1: %格式化（旧式）
message = "单价: %.2f元，数量: %d，总价: %.2f元" % (price, quantity, price * quantity)
# 方式2: format方法（推荐）
message = "单价: {:.2f}元，数量: {}，总价: {:.2f}元".format(price, quantity, price * quantity)
# 方式3: f-string（Python 3.6+，最简洁）
message = f"单价: {price:.2f}元，数量: {quantity}，总价: {price * quantity:.2f}元"

# 格式化语法细节
# {变量:格式说明符}
#   :.2f  - 保留2位小数
#   :8d   - 宽度8，右对齐整数
#   :<10s - 宽度10，左对齐字符串
#   :^10s - 宽度10，居中对齐字符串
#   :,    - 千位分隔符（仅数字）
num = 1000000
print(f"{num:,}")  # 输出: 1,000,000

    二、逻辑判断

    1. input 输入

    name = input("请输入名字：")
    ⚠️ input 返回值永远是字符串

    2. if 判断

    """
if 要判断的条件:
    条件成立时，要做的事情（仅在满足条件时执行）
else:
    条件不成立时，要做的事情（仅在不满足条件时执行）
"""
age = int(input("年龄："))

if age >= 18:
    print("成年")
else:
    print("未成年")

    3. if-elif-else

    """
if 要判断的条件1:
    条件1成立时，要做的事情（仅在满足条件1时执行）
elif 条件2:
    条件2成立时，要做的事情（仅在满足条件2时执行）
else :
    所有条件不成立时，要做的事情（仅在不满足所有条件时执行）
注：py语句中用缩进来表示归属关系，要求是4个空格
判断有顺序且互斥，顺序执行后满足其中一条条件就不会继续执行
"""
score = int(input("成绩："))
if score >= 90:
    print("优秀")
elif score >= 60:
    print("及格")
else:
    print("不及格")

    三、循环

    1. while 循环

    """
while 条件:
    条件成立时，要做的事情1
    条件成立时，要做的事情2
    …………
若想做到有限次数循环，有三个要素：
    1、循环控制因子（某个变量）
    2、循环控制条件（基于因子做判断）
    3、循环因子更新（修改因子的值，令因子可以在某一刻不满足条件）
"""
i = 0
while i < 5:
    print(i)
    i += 1
    * 注：多层嵌套尽量避免，三层以上的嵌套大概率可以通过算法优化

    2. for 循环

    • for循环是一种轮询机制，是对一批内容进行逐个处理
    • 无法定义循环条件，只能被动取出数据处理 
      """
for 临时变量 in 待处理数据集:
    循环条件满足时执行的代码
- range语句可以获取一个数字序列（可迭代类型的一种）
"""
for i in range(5):
    print(i)

    3. break / continue

    • break关键字：
    • 直接结束循环，只作用在本身所在循环
    • 可用于for循环和while循环
    • continue关键字：
    • 中断本次循环，直接进入下一次循环
    • 仅可控制自身所在循环的临时终端
    • for循环和while循环均可使用，效果一致

    四、函数

    1. 定义函数

    • 函数特征：组织好的，可重复使用的，用来实现特定功能的代码段
    • 将功能封装在函数内，可供随时随地重复使用
    • 函数封装可提高代码的复用性，减少重复代码，提高效率 
      """
def 函数名([传入参数]):
    函数体
    [return]
调用：函数名([参数])
返回值：函数再执行完成后，返回给调用者的结果，return后的代码不会执行
若函数无返回值，则结果为None
None作用：函数无返回值；if判断中等同false；定义无内容的变量
"""
def add(a, b):
    return a + b

    2. return 与 None

    • return 用于返回结果
    • 未写 return → 默认返回 None

    3. 参数类型

    参数 说明
    位置参数 按顺序
    默认参数 提供默认值
    关键字参数 指定名称 
    def func(a, b=10):
    return a + b

    4. 函数注释规范

    • 内容通常写在函数体之前
    • 标准的注释可以帮助理解函数使用函数 
      """
def func(x, y):
    """
    # 函数说明
    # :param x：形参x的说明
    # :param y：形参y的说明
    # :return： 返回值的说明
    """
    函数体
    return 返回值
"""

    5. 变量作用域

    • 通常分为局部变量和全局变量
    • 局部变量：定义在函数体内部的变量，仅在函数体内部生效
    • 可用于临时保存数据，函数调用完成后则销毁局部变量
    • 使用global关键字，即使在函数体内定义，仍为全局变量
    • 全局变量：在函数体内、外均可生效的变量

    6. 综合实践

    • 实现一个黑马ATM的效果
    • 默认余额为5000000元
    • 程序启动后要求输入客户姓名
    • 主菜单提示客户姓名的欢迎词，可以实现查询余额、存款、取款、退出四个功能
    • 除退出外，执行完对应任务可以返回到主菜单
    • 存款、取款后都应显示当前余额
    • 客户选择退出或输入错误，程序会退出，否则一直运行 
      """
print("欢迎来到黑马ATM")
name = input("请输入您的名字：")
money = 5000000
withdrawal_num = None
def main_screen():
    """
    ATM案例的主菜单函数，提示用户做输入，并返回用户输入的数字
    :return: 用户输入的数字
    """
    print('-'*10 + "主菜单" + "-"*10)
    print(f"{name}，您好，欢迎来到ATM，请选择操作：")
    print("查询余额 [输入1]")
    print("存款    [输入2]")
    print("取款    [输入3]")
    print("退出    [输入4]")
    return int(input("请输入您的选择："))
def balance_inquiry(selcet):
    """
    查询用户银行余额
    :return: None
    """
    if selcet != 0:
        print("----------------查询余额-----------------")
    print(f"{name}，您好,您的余额剩余：{money}元")
def deposit():
    """
    向用户余额存钱
    :return: None
    """
    global money
    print('-'*10 + "存款" + "-"*10)
    num = int(input(f"{name}，您好，您要存入多少元（请输入整数）："))
    print(f"{name}，您好,您存款{num}元成功")
    money += num
    balance_inquiry(0)
def withdrawal():
    global money
    print('-'*10 + "取款" + "-"*10)
    num = int(input(f"{name}，您好，您要取出多少元（请输入整数）："))
    if money > num:
        money -= num
        print(f"{name}，您好,您取款{num}元成功")
    else:
        print(f"{name}，您好,您取款{num}元失败")
    balance_inquiry(0)
while True:
    selcet = main_screen()
    if selcet == 1:
        balance_inquiry(1)
    elif selcet == 2:
        deposit()
    elif selcet == 3:
        withdrawal()
    else:
        print("欢迎下次来临，再见！")
        break

    五、数据容器

    • 一种可以容纳多份数据的数据类型，容纳的每一份数据称之为1个元素
    • 每一个元素，都可以是任意类型的数据，如字符串、数字、布尔等
    • 数据容器分为：列表(list)、元组(tuple)、字符串(str)、集合(set)、字典(dict)

    Python 五大核心数据容器对比表

    特性 列表 (list) 元组 (tuple) 字符串 (str) 集合 (set) 字典 (dict)
    定义符号 方括号 [] 圆括号 ()（可省略） 单/双/三引号 ''/""/""" 花括号 {}（无键值） 花括号 {key:value}

    六、函数进阶

    1️⃣ 函数返回多返回值

    def func():
    # 就是返回了（1，2）的元组
    return 1, 2
print(type(func()))             #输出结果： <class 'tuple'>

    2️⃣ 函数的多种传参方式

    1. 位置参数

    • 调用函数时根据函数定义的参数位置来传递参数
    • 传递的参数和定义的参数的顺序和个数必须一致 
      def user_info(name, age, gender):
    print(f"您的名字是{name}, 年龄是{age}, 性别是{gender}")
user_info("Tom", 20, "男")   #输出结果：您的名字是Tom, 年龄是20, 性别是男

    2. 关键字参数

    • 函数调用时通过“键=值”形式传递参数
    • 作用：可以让函数更加清晰、容易使用，同时也清除了参数的顺序需求.
    • 函数调用时，如果有位置参数时，位置参数必须在关键字参数的前面，但关键字参数之间不存在先后顺序 
      def user_info(name, age, gender):
    print(f"您的名字是{name}, 年龄是{age}, 性别是{gender}")
user_info(age=20, name="Tom", gender="男")   #输出结果：您的名字是Tom, 年龄是20, 性别是男
# 可以和位置参数混用，位置参数必须在前，且匹配参数顺序
user_info("Tom", age=20, gender="男")        #输出结果：您的名字是Tom, 年龄是20, 性别是男

    3. 缺省参数（默认参数）

    • 用于定义函数，为函数提供默认值，调用函数时可不传达改默认参数的值
    • 所有位置参数必须出现在默认参数前，包括函数定义和调用
    • 当调用函数时没有传递参数，就会使用默认缺省参数对应的值 
      def user_info(name, age, gender = "男"):
    print(f"您的名字是{name}, 年龄是{age}, 性别是{gender}")
user_info("Tom", 20)   # 输出结果：您的名字是Tom, 年龄是20, 性别是男
# 函数调用时，如果为缺省参数传值则修改默认参数值，否则使用这个默认值
user_info("Tom", 20, "女")        # 输出结果：您的名字是Tom, 年龄是20, 性别是女

    4. 不定长参数（可变参数）

    • 用于不确定调用的时候会传递多少个参数（不传参也可）
    • 通常将不定长参数命名为*args
    位置传递（元组接收）
    def func(name, *args):
    print(f"我们是{name}, 我们的成员有：", end="")
    for i in xxx:
        print(i, end=" ")
func("黑马", "周杰伦", "王力宏", "张学友", "刘德华")  
# 输出结果：我们是黑马, 我们的成员有：周杰伦 王力宏 张学友 刘德华
    关键字传递（字典接收）
    def func(name, **kwargs):
    print(kwargs)
func("aa", id = 1, age = 11, gender = "男", addr = "深圳石岩")  
# 输出结果：{'id': 1, 'age': 11, 'gender': '男', 'addr': '深圳石岩'}

    3️⃣ 匿名函数

    1. 函数作为参数传递

    • 形参：可以接收函数传入
    • 实参：传入实际函数 
      def func(compute):
    result = compute(1, 2)
    print(result)
def compute(x, y):
    return x + y
func(compute)   # 输出结果：3

    2. lambda匿名函数

    • 函数定义中，def可以定义有名称的函数，lambda可以定义匿名函数（无名称）
    • 无名称的匿名函数，只可临时使用一次，也只能写一行代码
    • 如果想要重复使用匿名函数，可以将匿名函数赋值给变量 
      """
定义方式： lambda 传入参数 : 函数体
"""
def func(compute):
    result = compute(1, 2)
    print(result)
func(lambda x, y: x+y)   # 输出结果：3

    八、异常、模块与包

    1️⃣ 异常

    • 程序运行中的错误

    🪝捕获异常

    • 提前假设某处会出现异常，做好提前准备 
      # try:
#     可能发生错误的代码，只有在try内部的代码才会被捕获异常
# except:                           # except Exception as e: 捕获全部异常
# except 异常类型 as 变量:            # 针对特定异常做捕获（可使用多个except区分不同异常类型）
# except (异常类型, 异常类型) as e:    # 针对多个特定异常做捕获,但无法区分
#     如果出现错误执行的代码
# else:
#     无异常执行的代码
# finally:
#     无论有无异常都执行的代码
try:
    f = open("word.txt", "r", encoding="utf-8")
except FileNotFoundError as e:
    f = open("word.txt", "w", encoding="utf-8")
    print(e)
print(f.read())
f.close()

    异常的传递性

    • 异常具有传递性，会将下层函数出现的异常传递给上层函数，若所有函数均为捕获异常，程序会报错
    • 利用这一特性可以在main函数中设置异常捕获，以保证程序正常运行

    2️⃣ 模块

    模块的导入

    • 模块是python文件，内涵模块、函数、类、变量等
    • 常用导入方式语法为：[form 模块名] import [模块 | 类 | 变量 | 函数 | 方法 | *] [别名]
    • 常用组合如下
    • import 模块名
    • import 模块名 as 别名
    • from 模块名 import 类、变量、方法等（用的时候无需模块.功能）
    • from 模块名 import * (导入模块中所有功能，但不建议使用，可读性差)
    • from 模块名 import 功能名 as 别名

    自定义模块

    # 如果本文件被直接执行，则内置变量__name__会被赋值为__main__
# 如果本文件被import或from导入，则内置变量__name__会被赋值为文件名称
# __name__是Python内置变量，任何代码文件都有
# 我们可以通过读取这个变量的值，从而确定这个代码文件是：被人导入了还是被作为程序执行了
if __name__ == '__main__':
    print("main")
