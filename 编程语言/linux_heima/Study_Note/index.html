    一、操作系统概述

    1、基础概念

    • 计算机由硬件和软件组成，操作系统属于软件的一类，用于协助用户调度硬件工作
    • 常见操作系统：Windows、Linux、MacOS、Android、鸿蒙等

    2、Linux入门

    • Linux内核是免费开源的，任何人都可以查看内核的源代码，甚至是贡献源代码。
    • 在内核之上，封装系统级应用程序，组合在一起就称之为Linux发行版。
    • 内核提供了Linux系统的主要功能，如硬件调度管理的能力；内核无法被用户直接使用，需要配合应用程序才能被用户使用。

    二、在虚拟机安装Ubuntu系统

    1、在官网下载Ubuntu镜像和VMware

    • Ubuntu下载地址：https://cn.ubuntu.com/download
    • VMware下载地址：https://vmwareoc.waltzsy.com/?bd_vid=11827811714261235814
    • 搜索教程进行安装，此处不进行赘述

    2、在Ubuntu环境下安装ssh，以便通过Moba远程

    • 命令 sudo apt install openssh-server -y （安装ssh）
    • 命令 sudo systemctl status ssh （检查ssh是否运行）
    • 命令 ip addr （查看UbuntuIP，通过Moba连接）

    三、Linux目录结构

    • Linux没有盘符概念，有且仅有一个根目录，层级关系使用/表示
    • 相对路径：以当前目录为起点，描述路径的一种写法，路径描述无需以/开头
    • 绝对路径：以根目录为起点,描述路径的一种写法,路径描述以/开头
    • 特殊路径符：
    • . 表示当前目录；.. 表示上一级目录； ~ 表示HOME/Desktop目录； - 表示回退到上一操作

    四、命令行

    1、基础概念

    • 学习Linux，本质上是学习在命令行下熟练使用Linux的各类命令。
    • 命令行：即Linux终端，可以提供字符化的操作页面供命令执行
    • 基础格式：command [-options] [parameter]
    • command命令本身
    • -options命令的一些选项，可以通过选项控制命令的行为细节
    • parameter命令的参数，多数用于命令的指向目标

    2、具体命令

    • ls [-a -l -h] [Linux路径]
    • 在命令行中，以平铺的形式，展示当前工作目录下的（非隐藏）内容
    • -a显示隐藏内容 -l列表展示详细文件信息 -h更人性化展示文件大小
    • cd [Linux路径]
    • 切换当前工作目录到指定Linux路径下
    • pwd
    • 查看当前所在的工作目录
    • mkdir [-p] Linux路径
    • 创建文件夹
    • -p表示自动创建不存在的父目录，是用于创建连续多层级的目录
    • touch Linux路径
    • 创建空白文件
    • cat Linux路径
    • 查看文件内容，将内容全部显示出来
    • more Linux路径
    • 查看文件内容，支持翻页，可以一页页展示，按空格翻页，按q 退出查看
    • cp [-r] 参数1 参数2
    • 复制文件和文件夹
    • -r用于文件夹复制 参数1被复制的 参数2要复制去的地方
    • mv 参数1 参数2
    • 移动文件和文件夹（Windows中的剪切）
    • 参数1被移动的 参数2要移动去的地方,如果不存在则改名
    • rm [-r -f] 参数1 参数2 ... 参数N
    • 删除文件和文件夹
    • -r删除文件夹 -f强制删除 参数被删除的文件或文件夹
    • rm -rf *.txt * 表示通配符，表示 删除全部以.txt结尾的
    • sudo -su
    • 切换root用户（超级管理员）
    • which 命令
    • 查看在Linux系统中所有可执行的命令的文件本地所在。
    • find 起始路径 -name "被查找的文件名"
    • 按文件名查找符合条件的文件所在
    • find 起始路径 -size +|-n(k|M|G)
    • 按文件大小查找符合条件的文件所在
    • +表示大于 -表示小于 n表示数字 k M G表示大小单位，k KB M MB G GB
    • grep [-n] "关键字" 输入内容
    • -n 显示过滤后的内容，在原始输入内容中的行号
