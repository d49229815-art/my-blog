    Python 基础语法¶

    一、基础语法¶

    1、基础概念¶

    1. 字面量（Literal）¶

    字面量是直接写在代码中的固定值，程序运行期间不会发生改变。

    类型 示例
    整数 10, -5
    浮点数 3.14
    字符串 "hello"
    布尔 True / False
    空值 None 
    print(10)
print("hello")
print(True)
print(None)

    2. 变量（Variable）¶

    变量是对象的引用名称，并不保存数据本身。

    x = 10
x = "hello"

    📌 特点： - 变量本身无类型 - 数据对象有类型 - 可反复赋值

    3. 字面量与变量（Variable）¶

    概念 说明 注意事项
    字面量 直接写在代码中的固定值 尽量避免直接使用，优先使用变量
    变量 存储运行过程中数据的容器 可重复使用、可修改、命名需规范

    3、数据类型系统¶

    类型 名称 是否可变
    int 整型 ❌
    float 浮点型 ❌
    str 字符串 ❌
    bool 布尔 ❌
    NoneType 空值 ❌
    #### 重要特性：
    * 使用type()函数查看数据类型：print(type(变量))
    * int可处理任意大整数，无溢出问题
    * 浮点数精度问题：0.1 + 0.2 != 0.3（二进制表示问题） 
    print(type(123))

    4. 赋值运算符¶

    # 基础赋值
x = 10
# 复合赋值（增强赋值）
x += 5      # x = x + 5
x -= 3      # x = x - 3
x *= 2      # x = x * 2
x /= 4      # x = x / 4
x //= 3     # x = x // 3
x %= 2      # x = x % 2
x **= 2     # x = x ** 2
# 链式赋值
a = b = c = 0
# 多重赋值
x, y, z = 1, 2, 3
# 交换变量值（Python特有）
x, y = y, x  # 无需临时变量

    6、字符串（str）¶

    1. 定义方式¶

    s1 = 'hello'
s2 = "world"
s3 = """多行字符串"""

    2. 常用转义字符¶

    转义符 含义 示例
    \n 换行 "Line1\nLine2"
    \t 制表符 "Name\tAge"
    \ 反斜杠 "C:\Windows"
    \' 单引号 'It\'s OK'
    \" 双引号 "He said \"Hello\""
    \r 回车 "Loading...\rDone"

    3. 字符串格式化¶

    # 1. 拼接
name = "Alice"
greeting = "Hello, " + name + "!"
# 2. 重复
divider = "-" * 30  # "------------------------------"
# 3. 格式化（三种方式）
price = 19.99
quantity = 3

# 方式1: %格式化（旧式）
message = "单价: %.2f元，数量: %d，总价: %.2f元" % (price, quantity, price * quantity)
# 方式2: format方法（推荐）
message = "单价: {:.2f}元，数量: {}，总价: {:.2f}元".format(price, quantity, price * quantity)
# 方式3: f-string（Python 3.6+，最简洁）
message = f"单价: {price:.2f}元，数量: {quantity}，总价: {price * quantity:.2f}元"

# 格式化语法细节
# {变量:格式说明符}
#   :.2f  - 保留2位小数
#   :8d   - 宽度8，右对齐整数
#   :<10s - 宽度10，左对齐字符串
#   :^10s - 宽度10，居中对齐字符串
#   :,    - 千位分隔符（仅数字）
num = 1000000
print(f"{num:,}")  # 输出: 1,000,000
