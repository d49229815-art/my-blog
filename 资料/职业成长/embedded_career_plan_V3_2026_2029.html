1. 个人路径概览

主结论：不要再收集新开发板、堆叠仪表/门禁/桌宠 Demo。你的决定性瓶颈是 C 指针与内存、数据结构、RTOS/OS、Linux 独立调试、英语与学历门槛。下一步应追求可被面试官验证的系统工程能力，而非更多功能截图。

当前

成人本科计算机在读，预计 2028-06 毕业；在职灯效嵌入式研发。专科现代通信技术，经历两轮车仪表、MCU C、工业协议、ESP32 和边缘设备项目。

2026Q4—2027

主攻 C / 数据结构 → MCU 驱动、通信、可靠性 → RTOS（实时操作系统）→ Linux（嵌入式操作系统）。形成 2–3 个“可深讲”模块。

2028—2029

2028 本科毕业，优先尝试全日制电子信息/计算机技术专硕；是否提前冲刺 2028 级取决于 2027 年底报考资格及模拟成绩。就业路线与升学路线明确分流。

三项现实约束

① 每日保底 1h、周末个人项目额外 3–5h，即约 8–12h/周；② 单个独立项目限 4–8 周，复杂系统按里程碑分割；③ 每月可支出 ¥500–1000，但当前存款薄，不是要求把预算花完。

⚠️ 收益不能混算：月薪 20k × 12 薪＝24 万税前年包；要达到税前年包 30 万，需要约 15 薪、额外绩效/奖金或更高月薪。2029 进入全日制硕士后的收入结构也与继续工作完全不同；“在读研”和“三年内达到年包30万”不能作为无条件并行 KPI。

用人岗位选项：汽车电子 MCU / 底层软件、工业设备研发（不以现场调试为主）、Embedded Linux 设备软件；AIoT/Edge AI 部署作为可选副线。纯数字孪生平台、纯算法研究、销售/FAE 不作为主职业线。

旧规划中出现的内容整合判定理由与处理
“非全日制研究生是唯一最优；100%满足需求”删除你现在明确 优先全日制，同时重视应届校招/实验室。非全只是经济及分数线约束下的备选，学校总学费也必须逐校核实。
“优先汽车电子 + Embedded Linux；保留工业协议经验”保留并整合按职业连续性构建 MCU/底软主线，工业控制仅优先企业内部研发、排除频繁驻场工作。
“ESP32-P4 人脸门禁 / 香橙派3B 车机 / 7寸MIPI必须做”退出主线最新可用设备明确为 TTGO POE、F103、8051、T133-S3、ESP32-S3、10.1寸 RGB、OV5647；P4 / 香橙派3B / 7寸MIPI未确认在手。
“数控电源 220V AC + PD3.1 + 0–60V 20A 一次做成”高风险，改为选修跨市电安规、功率环路和大电流，且两份方案的电压电流目标矛盾；只有低压隔离、限流模块的安全验证版可做。
“Git/Gitee 作品集模板、代码分层、测试日志、故障注入”保留每一项目都提供完整复现步骤、架构、单测、测试报告、演示视频；这是面试谈资。
“一年做 6–8 个完整大型项目，再同时软考+考研”压缩以 8–12h/周计算不现实；必做 3 个核心模块 + 可选 1 个拓展，备考冲刺则冻结新项目。
“参加 2027 年底初试；或 2028 年底初试”双窗口保留2027 年末初试对应 2028 级，须确保成人应届认定、学信网与学校附加要求；若备考不足，2028 年末冲 2029 级。
“软考/证书、人才补贴和院校录取数字永远有效”改成动态检查考试科目、招生、补贴金额、适用院校及补贴条件会变化。旧数字仅作历史参考，不作为未来现金流。

当前采购策略

先购确定需要的测试链：USB-CAN 或 CAN 收发器 ¥100–500；如有现成工具则 ¥0。先不买 Orange Pi 3B、ESP32-P4、7 寸 MIPI 屏。若 T133 的 Linux/外设条件验证失败，再讨论追加一块资料完整的 Linux SBC（¥400–1000，一次性采购）。

⚠️ 《便携式数控可调电源.html》提到的 220V 市电、PD3.1、0–60V/20A、大电流输出与多重保护，不允许按网页中的器件描述直接接线试制。最安全的学习版只接认证隔离式低压适配器和成熟 DC/DC 限流模块，用电子负载/保险丝/温度保护验证；不碰市电功率 PCB。若未来开展完整电源设计，需有合适实验条件与专业安全评审。

6. 项目驱动路线｜能在 1–2 个月交付

必做：P0、P1、P2（Linux gateway 完成一版）；职业分支加强：P3（汽车底软）或 P4（Linux 系统）；P5/PX 只能选其一作为加分项，不能并行。

所有项目按同一工程规范：src/、include/、tests/、docs/、hardware/、scripts/、README.md。工程名、版本、硬件接线、构建命令、测试日志、失败复现与演示视频缺一不可。

P0｜C 模块与测试基座　2026Q4 / 4 周

最小硬件

STM32F103 + PC；不额外买硬件

软件栈

C11 + GCC/CMake + Unity 或自写断言

验证交付物

ring buffer、消息队列、CRC、状态机，配 20+ 条单测；故意注入数组越界、队列满/空

时间与成本

¥0–100；8–10h/周

⚠️ 避坑：先把它当软件工程，不要为展示而加入屏幕。
P1｜CAN 灯效节点与诊断最小链　2026Q4–2027Q1 / 每版 6–8 周

最小硬件

STM32F103 + CAN 收发器 + USB-CAN/电脑；灯珠或模拟负载

软件栈

C + MCU 固件 + CAN 驱动 + Python 测试工具，择期加入 FreeRTOS

验证交付物

v1: CAN 帧→状态机→PWM/灯效→回应；v2: DBC 与简单诊断报文/日志；记录丢帧、重传、响应时间

时间与成本

¥100–500；8–12h/周

⚠️ 避坑：不是量产车规 ECU；ISO-TP/UDS/Bootloader 不要第一次就全塞进去。
P2｜POE 工业数据采集 + Linux 可靠网关　2027Q2–Q3 / 两个各 6–8 周

最小硬件

TTGO POE + PC 模拟 PLC；T133 SDK 成功后加入 Linux

软件栈

ESP-IDF + HTTP/MQTT、T133 C++ / socket + SQLite + systemd

验证交付物

断网 10min 缓存恢复；API 自动测试；日志轮转；设备重启/服务崩溃恢复；采集到上报链路数据表

时间与成本

¥0–300；8–12h/周

⚠️ 避坑：先复用 PLC 协议经验，避免无真实 PLC 而卡住；可模拟 Modbus/TCP。
P3｜RTOS + 安全升级/汽车诊断强化包　2027Q3–Q4 / 两个各 6–8 周

最小硬件

复用 STM32F103、USB-CAN；Flash 预算不足时 PC 模拟分区

软件栈

FreeRTOS + ISO-TP 最小实现 + UDS 核心服务 + CRC/固件版本 + Python 刷写工具

验证交付物

演示会话进入、DID 读取、分块升级模拟、异常刷写恢复；≥30 个测试用例、任务栈水位与故障记录

时间与成本

¥0–300；9–12h/周

⚠️ 避坑：若 F103 Flash/Bank 不支持可靠 A/B 更新，则用 PC 仿真回滚逻辑并说明限制。
P4｜T133 Linux 平台与 HMI/摄像头　2028 上半年 / 6–8 周，条件式

最小硬件

T133-S3 + 10.1寸 RGB 屏；相机仅在兼容后加入

软件栈

交叉编译 + Device Tree(设备树) + Linux C++ + framebuffer/Qt 可选

验证交付物

系统启动日志、UI/触摸最小演示、调试报告、至少一次系统服务 crash 定位与修复

时间与成本

¥0–400；技术≤6h/周

⚠️ 避坑：若备考冲刺或 SDK 适配超出两周，冻结该项目，改为纯 Linux daemon。
P5｜边缘视觉推理部署（可选）　2029 上半年 / 6–8 周，条件式

最小硬件

T133 若算力和摄像头支持；否则电脑/可购买 Linux SBC

软件栈

OpenCV + ONNX Runtime/TFLite + Linux C++/Python

验证交付物

录制视频/实时摄像头输入→推理→告警；FPS/P95/内存/冷启动数据与故障处理

时间与成本

¥0–1000；项目先评估现有硬件

⚠️ 避坑：不自行训练大模型，不承诺 1 秒/95% 等未经采样验证指标。
PX｜数控电源安全版（选修）　备考结束后 / 6–8 周

最小硬件

认证隔离 DC 供电 + 低压成熟 DC/DC 模块 + 仪表

软件栈

MCU 采样/显示/温控与故障状态机，功率环节不自制高压部分

验证交付物

低压范围精度校准、过流/过温/短路受控测试报告

时间与成本

¥150–600；6–8h/周

⚠️ 避坑：不是 220V 或 0–60V 20A 量产方案；测试须具备限流与过温保护。

没有找到面向硕士公开的“必须发表 X 篇”规定。学院当前公开文件页明确列博士科研成果考核标准，不能反推硕士“必须发”或“不用发”。你的安全目标应是研二前形成论文/专利/系统 benchmark 中至少一种成果。

你要提前补

C/C++ 指针/内存 → 数据结构 → Linux/OS → 计算机组成与体系结构 → CMake/GDB/perf → 数字逻辑 → Verilog/FPGA 基础。你已有 MCU 和硬件调试，真正缺的是系统层。

关键验证问题：“老师，近两届计算机技术专硕主要课题中，Embedded Linux/系统软件、异构 SoC、FPGA 软硬协同各占多少？学生通常做到驱动/OS 层，还是以 FPGA 算法硬件化为主？”
来源：杨全胜官方主页；系统结构研究室历届研究生页。

11.2 单冯｜智能嵌入式 + IoT + 调度优化

技术跨度最大的一条升级路线

11.4 董永强｜工业控制网络 / TSN / Linux 网络系统

近 5 年论文/学生

11.6 “发表要求”怎么理解

⚠️ 不要使用“某导师不要求小论文”这种未经确认的说法。截至 2026-09-29，我没有在计算机学院公开文件中找到“085404 计算机技术硕士必须发表 ≥1 篇论文”的当前明文，也不能由此推出“不需要成果”。学院文件页明确公开了博士科研成果考核标准；硕士仍有开题、中期、实践、学位论文评阅/答辩等环节。你 2029 入学时必须以当年培养方案为准。

你自己的安全目标：研二结束前至少形成：①论文投稿/录用；②发明专利；③可复现实验系统 + benchmark；④企业项目验收模块——四者至少一项。这个是职业规划目标，不是学校官方毕业条件。

12.1 我会怎样从现在开始“提前当你的研究生导师”

Stage 0｜现在—考研前

每完成一个项目，不以“能跑”为验收，而以：研究问题、baseline、量化指标、实验设计、失败分析验收。

Stage 1｜模拟研一

每周一篇与你项目直接相关的论文/技术报告，复现一个小点；日志从“今天做了什么”改成“假设→实验→数据→结论”。

Stage 2｜模拟研二

选一个项目升级成准硕士课题：2–3 个 baseline，对照/消融/长稳实验，写 15–25 页技术报告。

Stage 3｜模拟研三

完整模拟“开题—中期—预答辩—答辩”，重点追问创新点、实验公平性和结论边界。

⚠️ 你现在最适合先体验“杨全胜方向模拟”。它不会让你立刻跨到纯算法，而是把现有 MCU/CAN/ESP32/工业协议经验逐步抬到 Linux、OS、体系结构和软硬协同。等数据结构、Linux、C++ 能独立做项目后，再切单冯/东方模拟，检验你是否真喜欢调度算法或 Edge AI，而不是只被方向名称吸引。
