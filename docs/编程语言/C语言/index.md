## 🧩环境搭建
### 1. 安装C编译器
#### 1.1.1 安装GCC
    1. 安装GCC
        1. 从GCC官网下载GCC安装包
        2. 运行安装包，选择默认选项即可
#### 1.1.2 安装MinGW
    1. 安装MinGW
        1. 从MinGW官网下载MinGW安装包
            这里是MinGW的github下载地址：https://github.com/msys2/msys2-installer/releases/
        2. 运行安装包，选择默认选项即可
        3. 安装MinGW的工具链
            1. 打开MinGW的命令行    
            2. 输入以下命令安装工具链
                *pacman -S --needed base-devel mingw-w64-ucrt-x86_64-toolchain*
    2. 配置环境变量
        1. 打开环境变量设置
        2. 点击“环境变量”按钮
        3. 在“系统变量”中，找到“Path”变量，点击“编辑”按钮
        4. 添加MinGW的bin目录（如C:\MinGW\bin）到变量值中
        5. 点击“确定”按钮保存
#### 1.1.3 安装Visual Studio Code
    1. 安装Visual Studio Code
        1. 从Visual Studio Code官网下载Visual Studio Code安装包
        2. 运行安装包，选择默认选项即可
    2. 配置C++环境，安装插件（如C/C++、C/C++ Extension Pack等）
        1. 打开Visual Studio Code
        2. 点击“扩展”按钮
        3. 搜索“C/C++”插件
        4. 点击“安装”按钮安装
#### 1.1.4 点击“重启”按钮重启Visual Studio Code
5. 重启Visual Studio Code
