一、项目整体需求规格

1.1 电源输入规格

  • 输入1：220V 家用交流电市电输入
  • 输入2：Type-C 接口 PD3.1 快充输入，最高28V/5A
  • 逻辑：防多路电源同时接入，自动优先级切换

1.2 输出参数区分

220V市电输入模式

电压：0~60V连续可调，步进0.1V，精度±0.05V

电流：0~10A连续可调，步进0.01A，精度±0.01A

Type-C PD输入模式

电压：0~60V可调，步进0.1V，精度一致

电流：0~5A可调，步进0.01A，精度±0.01A

1.3 核心功能需求

  • 恒压CV / 恒流CC 模式全自动切换，带指示灯提示
  • 屏幕：2.4寸及以上 SPI/RGB 触摸彩屏，实时显示电压/电流/功率/设定值
  • 操控：实体按键+旋转编码器快速调压调流，支持多组参数预设保存调用
  • 智能功率约束：输出功率不大于输入功率，电压电流线性限流
  • 全保护：过压、过流、过温、短路、防反接、防倒灌

1.4 结构与外观约束

  • 整机外壳最大尺寸：88*39*120mm，极致紧凑轻量化
  • 防护等级：防尘、防溅水、抗摔便携设计
  • 散热：主动风扇+被动散热组合风道设计
  • 开发优先级：性价比高、器件通用易采购、替换方便

1.5 项目开发时间规划

5月完成全部原理图设计 → 6月20日前完成PCB绘制、打板、贴片 → 7月完成全套固件程序调试与整机量产测试

二、核心主控与电源芯片选型

2.1 主控芯片：乐鑫 ESP32-S3

  • 双核高主频，算力充足，同时处理PID稳压、采样、屏幕、蓝牙WiFi多任务
  • 内置多路12位ADC，满足高精度电压电流采样需求
  • 自带WiFi+BLE蓝牙，无需额外外设，直接实现远程控制
  • 丰富SPI/I2C/GPIO，完美驱动彩屏、编码器、风扇、保护电路
  • ESP-IDF生态成熟，开发速度快，固件升级便捷

2.2 功率主控芯片：屹晶微 EG1163S

  • 高压大电流专用降压电源芯片，适配本项目0~60V大功率输出场景
  • 支持宽压输入，适配市电整流高压与PD低压双输入场景
  • 支持外部闭环反馈，可由ESP32精准调节输出电压电流
  • 内置逐周期限流，硬件级别基础过流保护，搭配软件双重防护
  • 市面货源稳定，性价比高，适合批量量产

三、整机硬件系统总架构

整体架构分为七大独立模块，模块化设计，故障易排查，开发分层清晰：

  1. 双路电源输入模块（220V AC整流 + Type-C PD协议诱骗）
  2. 输入智能切换+防互斥保护模块
  3. EG1163S核心DC-DC功率变换主回路
  4. 高精度电压、电流、温度采样反馈模块
  5. ESP32-S3主控逻辑控制单元
  6. 人机交互单元（彩屏+按键+编码器）
  7. 驱动执行单元（风扇驱动、保护切断、指示灯、通信外设）

控制逻辑：ESP32采集实时输出参数 → 运行双闭环PID算法 → 调节EG1163S反馈基准 → 稳定输出电压电流，同时实时判定工作模式与功率上限。

四、双路电源输入电路详细设计

4.1 220V交流市电输入支路

流程：220V市电 → EMI滤波电路 → 全桥整流桥 → 高压直流母线 → 预稳压电路 → 接入EG1163S主功率输入端

  • 增加压敏电阻、TVS管，抑制电网浪涌冲击
  • 整流后预留大容量电解电容储能，降低纹波
  • 增加软上电电路，避免上电大电流冲击

4.2 Type-C PD3.1快充输入支路

  • 采用PD协议诱骗芯片，自动握手5V/9V/12V/15V/20V/28V全档位
  • 最高支持28V5A输入功率140W
  • 输入端配置自恢复保险丝+ESD防护
  • 支持识别E-Marker线缆，自动限制输入电流

4.3 双输入互斥防冲突电路

  • 硬件二极管隔离 + ESP32逻辑检测双重防护
  • 禁止220V与Type-C同时供电，杜绝倒灌烧毁电源
  • 优先级设定：默认优先Type-C便携输入，功率不足自动切市电
  • 多路同时接入时蜂鸣器报警提示

五、EG1163S主功率回路设计

5.1 芯片外围基础电路

  • 配置芯片使能引脚、频率设定引脚、基准电压引脚
  • 预留频率可调点位，适配不同功率下效率优化
  • 电源供电独立LDO稳压，避免功率纹波干扰控制端

5.2 同步整流功率管选型

  • 耐压选型大于75V，预留安全余量
  • 低内阻大电流MOS管，降低导通发热损耗
  • 搭配续流功率电感+高低频组合滤波电容
  • 输出端预留防反接大功率肖特基二极管

5.3 数控可调闭环反馈设计

传统固定反馈改为**ESP32数控可调基准反馈**：

  • ESP32通过DAC/精密分压电路动态修改EG1163S FB反馈电压
  • 实现0~60V无级精细调压，满足0.1V步进精度
  • 电流采样信号送入主控，实现恒流限流闭环控制

六、高精度电压&电流采样系统

6.1 电压采样电路

  • 采用低温漂高精度金属膜电阻分压，阻抗匹配优化
  • RC二阶滤波滤除开关电源高频杂波
  • 送入ESP32-S3 ADC采集，软件多点均值滤波
  • 校准后精度稳定达到 ±0.05V 满足设计指标

6.2 大电流高精度采样电路

  • 串联大功率毫欧级锰铜采样电阻，温漂极低
  • 搭配精密差分运放放大微弱电流信号
  • 消除共模干扰，满载10A下依旧保证0.01A步进与精度
  • 采样信号同时用于硬件限流+软件限流双重判定

6.3 温度采样电路

  • NTC热敏电阻紧贴功率MOS与EG1163S热源布局
  • 实时采集内部温度，作为散热与过温保护依据

九、整机全维度安全保护体系

保护类型 触发条件 执行动作
输出过压保护OVP 输出电压超出设定阈值 立即关断输出，屏幕弹窗告警
输出过流保护OCP 电流超过设定限流值 自动切入恒流模式，超限直接关停
短路保护SCP 输出正负极直接短路 打嗝式间歇保护，防炸机
过温保护OTP 内部热源温度超标 全速风扇散热，超温直接切断输出
输出防反接保护 负载正负极接反 硬件阻断，无电流输出
双输入互斥保护 AC+Type-C同时插入 锁定单路输入，声光提示

十、智能功率线性限制算法（核心需求实现）

实现规则：输出总功率永远不超过当前输入最大可提供功率，电压与输出电流呈线性约束关系

  • 示例1：输入24V/5A，总输入功率固定上限
  • 设定输出10V时，允许最大输出电流自动放宽
  • 设定输出20V时，自动压低最大允许输出电流
  • 全局硬限制：无论任何工况，整机最大输出电流不超过20A（软件死限）
  • 降压架构严格遵循：输出功率 ≤ 输入功率×转换效率
  • 主控实时计算剩余功率余量，动态刷新最大可输出电流值

该逻辑完全由ESP32软件算法实现，无需改动硬件，后期可自由修改功率曲线参数。

十四、项目BOM成本与供应链管控

成本设计原则

  • 优先选用通用量产通用料，少用冷门专用芯片
  • 功率器件预留替代型号，防止缺货断供
  • 分层成本控制：主控、电源、屏幕、结构、外设分开管控

批量量产成本区间

整机不含外壳固件：百元级别低成本方案，性价比极高，创客/商用批量均可落地

供应链建议

  • ESP32系列走乐鑫正规代理渠道，保障货源稳定
  • EG1163S直接对接屹晶微授权经销商
  • 阻容感、接插件、屏幕通用物料走一站式电子商城备货
  • 建立2套以上备选器件方案，应对涨价与断货风险

十五、整机验收测试标准

电气精度测试

  • 电压全段0~60V输出误差 ≤ ±0.05V
  • 电流0~10A/0~5A输出误差 ≤ ±0.01A
  • 调节步进响应流畅无卡顿

模式切换测试

满载轻载切换下CV/CC切换平稳，无电压电流跳变、无震荡

保护功能全测

短路、过流、过压、反接、过温全部触发正常，不误保护、不拒保护

长时间老化测试

满载连续工作4小时以上，温度正常、参数无漂移、无异常发热

通信与交互测试

屏幕触控灵敏、编码器调节顺畅、蓝牙WiFi连接稳定、预设参数保存不掉电丢失
